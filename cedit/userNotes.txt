--If some variables are mixed into an init list without inits, spacing should
take them into account.

Old:

    int  x;
    int  y;
    int  i  =  0;
    int  yPos;
    int  spriteA;


New/correct:

    int  x;
    int  y;
    int  i         =  0;
    int  yPos;
    int  spriteA;

I.e, there should be room for two spaces AFTER the uninitialized variable's ; and the start of the = column.
