--When formatting block comments, it should auto-indent everything inside the comment by two spaces, like this:


/*
  Test comment.
  This is a test.

  This is another test.


  This is another test.
*/


And if the user manually indents more than that, that indent should be continued on subsequent lines (as long as there is no black line in between).  You're already doing this correctly, so don't break it.  The main thing is auto-indenting everything in a block comment by 2 spaces by default.

/*
  Here is a quote:

      Quote first line
	  Quote second line

  Text after the quote.
*/
