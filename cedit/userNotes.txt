A few things:

--The program doesn't currently play well with the way selected text in X windows automatically gets copied into some kind of clipboard buffer (usually pasted with the middle mouse button).   Neither selecting (without manually executing a copy operation), nor pasting with the middle mouse button currently works.  Seems like emacs supports two different copy-paste buffers (one for manual copy operations, and the other for the current selection), and most X windows programs support these two different buffers also.


--There should be spaces around equality tests, like this:

if( x == 5 ) {
    }

if( y > 10 ) {

    }


--Boolean operations should be split up on multiple lines, with the boolean operator on a line by itself, like this:

if( x == 10
    &&
	y > 20 ) {
	}
